# 用户标记与评论收藏器 - 使用说明

## 快速开始

### 1. 安装插件

#### 方法一：通过Chrome扩展程序页面
1. 打开Chrome浏览器
2. 访问 `chrome://extensions/`
3. 启用"开发者模式"（右上角开关）
4. 点击"加载已解压的扩展程序"
5. 选择 `user-comment-manager` 文件夹

#### 方法二：通过安装脚本
```bash
cd user-comment-manager
./install.sh
```

### 2. 基本使用

#### 标记用户
1. 访问支持的网站（知乎、IT之家、微博）
2. 找到用户元素（用户名、头像、用户链接）
3. 点击用户旁边的"标记"按钮
4. 在弹出的对话框中填写：
   - 备注信息（可选）
   - 标签（用逗号分隔，如：专家, 活跃用户）
   - 选择标记颜色
5. 点击"确认标记"

#### 收藏评论
1. 在支持的网站上找到评论
2. 点击评论旁边的"收藏"按钮
3. 在弹出的对话框中填写：
   - 备注信息（可选）
   - 标签（用逗号分隔，如：重要, 有趣）
4. 点击"确认收藏"

### 3. 查看和管理数据

#### 打开弹出窗口
1. 点击浏览器工具栏的插件图标
2. 弹出窗口会显示：
   - 标记的用户列表
   - 收藏的评论列表
   - 标签云
   - 搜索框

#### 搜索和筛选
1. 在搜索框中输入关键词
2. 点击标签云中的标签进行筛选
3. 点击"全部"标签清除筛选

#### 查看详情
1. 点击用户项查看用户主页
2. 点击评论项查看评论所在页面
3. 点击"查看"按钮打开相关页面

#### 删除数据
1. 点击用户项旁边的"删除"按钮
2. 点击评论项旁边的"删除"按钮
3. 确认删除操作

### 4. 数据管理

#### 导出数据
1. 在弹出窗口中点击"导出"按钮
2. 选择导出类型：
   - 导出所有数据
   - 仅导出用户
   - 仅导出评论
3. 下载JSON文件

#### 导入数据
1. 在弹出窗口中点击"导入"按钮
2. 选择JSON文件
3. 点击"导入"按钮
4. 数据将与现有数据合并

### 5. 配置插件

#### 打开设置页面
1. 在弹出窗口中点击"设置"按钮
2. 或者访问 `chrome://extensions/`
3. 找到插件，点击"详情"
4. 点击"扩展程序选项"

#### 网站配置
1. 在"网站配置"标签页中
2. 勾选要启用的网站
3. 点击"保存配置"

#### 数据管理
1. 在"数据管理"标签页中
2. 查看统计信息
3. 导出/导入数据
4. 清除数据

#### 外观设置
1. 在"外观设置"标签页中
2. 选择默认标记颜色
3. 自定义按钮文本
4. 配置行为选项

## 网站适配说明

### 知乎 (zhihu.com)
- **用户元素**：`.author-link`, `.user-link`, `.author-info`
- **评论容器**：`.comment-list`, `.comment-item`
- **支持页面**：问答页面、回答页面、用户主页

### IT之家 (ithome.com)
- **用户元素**：`.comment-author`, `.user-name`
- **评论容器**：`.comment-list`, `.comment-item`
- **支持页面**：文章页面、评论页面

### 微博 (weibo.com)
- **用户元素**：`.W_name`, `.user-name`, `.avatar`
- **评论容器**：`.WB_feed_detail`, `.comment-list`
- **支持页面**：微博详情页、用户主页

## 故障排除

### 问题：标记按钮不显示
**解决方案**：
1. 检查网站是否在支持列表中
2. 重新加载页面
3. 检查插件是否已启用
4. 查看控制台错误信息

### 问题：数据无法保存
**解决方案**：
1. 检查Chrome存储权限
2. 清除浏览器缓存
3. 重新安装插件
4. 检查存储空间是否充足

### 问题：导入失败
**解决方案**：
1. 检查JSON文件格式
2. 确保文件未损坏
3. 检查文件版本兼容性
4. 尝试重新导出数据

### 问题：插件无法加载
**解决方案**：
1. 检查Chrome版本（需要88+）
2. 重新加载扩展程序
3. 检查manifest.json语法
4. 查看Chrome扩展程序页面的错误信息
