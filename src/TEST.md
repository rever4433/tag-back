# 用户标记与评论收藏器 - 测试指南

## 测试目标

本测试指南将帮助您验证插件的所有核心功能是否正常工作。

## 测试环境

- **浏览器**：Chrome 88+
- **操作系统**：Windows/macOS/Linux
- **测试网站**：知乎、IT之家、微博

## 测试用例

### 测试1：安装和加载

**目标**：验证插件正确安装和加载

**步骤**：
1. 打开 `chrome://extensions/`
2. 启用"开发者模式"
3. 加载插件
4. 检查插件图标是否显示在工具栏

**预期结果**：
- 插件图标显示在工具栏
- 插件状态为"已启用"
- 无错误信息

### 测试2：知乎用户标记

**目标**：验证在知乎上标记用户功能

**步骤**：
1. 访问 https://www.zhihu.com/
2. 浏览到一个问题页面
3. 找到用户元素（用户名、头像）
4. 点击"标记"按钮
5. 填写备注和标签
6. 选择颜色
7. 点击"确认标记"

**预期结果**：
- 用户旁边显示"标记"按钮
- 标记对话框正常显示
- 标记成功后显示标记标识
- 数据正确保存到存储中

## 测试问题排查

### 问题：标记按钮不显示
**可能原因**：
1. 网站不在支持列表中
2. DOM结构变化
3. 插件未正确加载

**解决方案**：
1. 检查manifest.json中的host_permissions
2. 更新网站适配器
3. 重新加载插件

### 问题：数据无法保存
**可能原因**：
1. Chrome存储权限问题
2. 存储空间不足
3. 数据格式错误

**解决方案**：
1. 检查Chrome存储权限
2. 清理浏览器缓存
3. 检查数据格式

### 问题：导入失败
**可能原因**：
1. JSON文件格式错误
2. 文件损坏
3. 版本不兼容

**解决方案**：
1. 验证JSON格式
2. 重新导出数据
3. 检查版本兼容性
