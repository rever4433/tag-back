# 用户标记与评论收藏器 - 演示指南

## 演示目标

本演示将展示如何使用用户标记与评论收藏器插件来：
1. 在知乎网站上标记用户
2. 在IT之家网站上收藏评论
3. 在微博网站上管理数据
4. 使用搜索和筛选功能
5. 导出和导入数据

## 演示步骤

### 步骤1：安装插件

```bash
# 进入项目目录
cd user-comment-manager

# 运行安装脚本
./install.sh

# 或者手动安装：
# 1. 打开 chrome://extensions/
# 2. 启用"开发者模式"
# 3. 点击"加载已解压的扩展程序"
# 4. 选择当前目录
```

### 步骤2：访问知乎并标记用户

1. **打开知乎**
   - 访问 https://www.zhihu.com/
   - 登录您的账户

2. **找到用户**
   - 浏览问题或回答
   - 找到您感兴趣的用户

3. **标记用户**
   - 在用户名旁边会显示"标记"按钮
   - 点击"标记"按钮
   - 填写备注：例如"领域专家"
   - 添加标签：例如"专家, 活跃用户"
   - 选择标记颜色：例如蓝色
   - 点击"确认标记"

4. **验证标记**
   - 用户名旁边会显示标记标识
   - 标识显示标签和颜色

### 步骤3：访问IT之家并收藏评论

1. **打开IT之家**
   - 访问 https://www.ithome.com/
   - 浏览文章

2. **找到评论**
   - 滚动到文章底部的评论区
   - 找到有价值的评论

3. **收藏评论**
   - 在评论旁边会显示"收藏"按钮
   - 点击"收藏"按钮
   - 填写备注：例如"重要观点"
   - 添加标签：例如"重要, 有趣"
   - 点击"确认收藏"

4. **验证收藏**
   - 评论旁边会显示"已收藏"标识
   - 按钮颜色变为紫色

### 步骤4：访问微博并管理数据

1. **打开微博**
   - 访问 https://weibo.com/
   - 浏览微博动态

2. **标记用户和收藏评论**
   - 按照步骤2和3的方法
   - 在微博上标记用户和收藏评论

3. **查看数据**
   - 点击浏览器工具栏的插件图标
   - 查看标记的用户列表
   - 查看收藏的评论列表

### 步骤5：使用搜索和筛选功能

1. **打开弹出窗口**
   - 点击插件图标

2. **搜索用户**
   - 在搜索框中输入用户名
   - 按回车或点击"搜索"按钮
   - 查看搜索结果

3. **筛选标签**
   - 点击标签云中的标签
   - 查看筛选结果
   - 点击"全部"清除筛选

4. **切换标签页**
   - 点击"用户列表"标签
   - 点击"评论收藏"标签

### 步骤6：导出数据

1. **导出所有数据**
   - 在弹出窗口中点击"导出"按钮
   - 下载JSON文件
   - 文件包含所有标记和收藏数据

2. **导出特定数据**
   - 在设置页面中
   - 点击"仅导出用户"或"仅导出评论"
   - 下载对应的JSON文件

3. **验证导出**
   - 打开下载的JSON文件
   - 检查数据完整性

### 步骤7：导入数据

1. **准备数据文件**
   - 使用之前导出的JSON文件
   - 或者创建符合格式的JSON文件

2. **导入数据**
   - 在弹出窗口中点击"导入"按钮
   - 选择JSON文件
   - 点击"确认导入"

3. **验证导入**
   - 刷新弹出窗口
   - 检查数据是否正确导入
   - 数据会与现有数据合并

### 步骤8：配置插件

1. **打开设置页面**
   - 在弹出窗口中点击"设置"按钮
   - 或者访问 `chrome://extensions/`
   - 找到插件，点击"扩展程序选项"

2. **配置网站**
   - 在"网站配置"标签页中
   - 勾选或取消勾选网站
   - 点击"保存配置"

3. **配置外观**
   - 在"外观设置"标签页中
   - 选择默认标记颜色
   - 自定义按钮文本
   - 配置行为选项

4. **管理数据**
   - 在"数据管理"标签页中
   - 查看统计信息
   - 清除不需要的数据

## 演示问题排查

### 问题1：插件图标不显示
**解决方案**：
1. 检查Chrome扩展程序页面
2. 确保插件已启用
3. 重新加载扩展程序

### 问题2：标记按钮不显示
**解决方案**：
1. 检查网站是否在支持列表中
2. 刷新页面
3. 检查控制台错误

### 问题3：数据无法保存
**解决方案**：
1. 检查Chrome存储权限
2. 清除浏览器缓存
3. 重新安装插件

### 问题4：导入失败
**解决方案**：
1. 检查JSON文件格式
2. 确保文件未损坏
3. 检查文件版本
